Model guide

Current on-device speech models, matched to this Windows computer instead of treating every laptop like a CPU-only machine.

LOW-LATENCY GPU

Parakeet TDT 0.6B v3 Q8 RECOMMENDED
The accuracy-first English default. It stays resident on the GPU and includes punctuation and capitalization.
Nemotron 3.5 Streaming Q8
Cache-aware 600M streaming ASR with broad multilingual support. Choose it when multilingual recognition matters more than maximum English accuracy.
Nemotron Streaming English Q8
The focused English-only option. NVIDIA recommends it when multilingual recognition is not needed.

CPU FALLBACK

Whisper Tiny / Base / Small Q5
Compact fallbacks for computers without a compatible GPU. They run locally but are intentionally labeled CPU because this build does not disguise CPU Whisper as accelerated.
